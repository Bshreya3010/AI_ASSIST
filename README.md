# Refactoring Code

Refactoring means improving the structure and readability of code without changing what the program does.

## Why refactor code?

- Makes code easier to understand
- Improves maintainability
- Helps other developers read and modify it quickly
- Keeps the program clean and professional

## Example

Before refactoring, the code used a generic variable name such as `num` and a simple print statement. After refactoring, it uses a clearer name like `number` and f-strings for cleaner output.

```python
# Program to check whether a number is even or odd
number = int(input("Enter a number: "))

if number % 2 == 0:
    print(f"{number} is even")
else:
    print(f"{number} is odd")
```

## Key refactoring ideas

- Use meaningful variable names
- Keep the code simple and readable
- Remove unnecessary complexity
- Write code in a way that is easy to follow

Refactoring is not about changing the logic of the program; it is about making the code cleaner, easier to read, and easier to maintain.
